## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by emailing
**tristandevelliott1996@gmail.com**.

Do not open a public issue. We will acknowledge receipt within 48 hours and
provide an estimated timeline for a fix. Once the vulnerability is resolved,
we will notify you and publish an advisory if appropriate.
